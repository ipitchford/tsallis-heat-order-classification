## What the result says

For the universal alternating-derivative property under Gaussian heat flow, the positive Tsallis order is admissible exactly when it is two. The new nonexceptional-order construction adapts an existing periodic/Gaussian mechanism; the Shannon counterexample and quadratic positivity are inherited and attributed. Each fixed nonexceptional order has a sufficiently large derivative threshold and a density depending on that derivative order. This is not one density simultaneously defeating all orders.

A separate explicit witness has Tsallis order 3/2, derivative order 13 and positive heat time 1/50. It is smooth and positive, but is not claimed log-concave or least-order. The elementary dilation corollary permits unit variance or a prescribed positive failure time, not independent choices of both.
